# Where are the candidates expressed in tissue, and can histology see them?

Study 3 of a breast-cancer series: the candidate drug targets of
[study 2](https://github.com/Natalija-Stepurko/brca-target-evidence) mapped onto spatial transcriptomics
sections, and a test of whether a pathology foundation model predicts them from H&E.

Status: repository initialised 2026-10-07. The design is pre-registered in `docs/DESIGN.md` before any
data are downloaded; the project page and the literature follow in the next pull requests.
